# Contributing to LocalConnect

We love your input! We want to make contributing to LocalConnect as easy and transparent as possible.

## Development Setup

1. Fork the repo
2. Clone your fork
3. Create a branch (`git checkout -b feature/amazing-feature`)
4. Make your changes
5. Commit (`git commit -m 'Add amazing feature'`)
6. Push to your fork
7. Open a Pull Request

## Code Standards

- Use TypeScript for frontend/mobile
- Use Python type hints for backend
- Write tests for new features
- Follow the existing code style
- Format code with `npm run format`

## Commit Messages

- Use clear, descriptive commit messages
- Reference issues when relevant (#123)
- Use present tense ("Add feature" not "Added feature")

## Pull Request Process

1. Update README.md with any new dependencies or setup changes
2. Add tests for new functionality
3. Ensure all tests pass
4. Get approval from maintainers
5. Squash commits before merging

## Questions?

Feel free to open an issue or contact the maintainers.
